# من غير إذن · Editorial V2

Redesigned responsive Egyptian feminist publication. Arabic-first with English versions via `?lang=en`.

- One original long-form feature at `/articles/lip-gloss/`
- 31 preserved bilingual RAW by Vee reading pages at `/archive/<post-id>/`
- Live archive search, category filtering, original art and TikTok links
- Editorial home, About and Contribute pages
- Search/social metadata and sitemap
- Original site saved verbatim as `original-2026-11-15.html`
- Legacy `#post-...`, `#raw-...`, `#lip-gloss` links redirect from homepage

Shared `site.css` and `site.js` require no build step. The homepage embeds the bilingual Beehiiv newsletter signup. The Contribute page embeds the existing bilingual Tally pitch form. Each page includes a direct link if the embed cannot load. TikTok remains available as the social-follow link.
